# CS116 – Lập trình Python cho máy học (UIT, CS116.R11)

- `CS116.R11_Lab4_Solution.ipynb`, `CS116.R11_Lab5_Solution.ipynb` – bài thực hành.
- `Kaggle project/` – đồ án cuối kỳ: Kaggle Playground Series S6E10 *Predicting Airline Satisfaction*.
  - `src/` – pipeline (EDA, feature engineering, GBDT/NN models, stacking, hyper-parameter tuning).
  - `docs/` – báo cáo đồ án, hình EDA.
  - `kaggle_kernels/` – kernel fine-tune TabPFN chạy trên Kaggle GPU.
  - `logs/cv_results.csv` – mọi lần chạy cross-validation.
  - Dữ liệu (`data/`), dự đoán OOF (`oof/`, `test_preds/`) và `submissions/` không đưa lên git; tải lại bằng `kaggle competitions download -c playground-series-s6e10`.
